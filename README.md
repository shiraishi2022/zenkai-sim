# 全壊棟数の最低値の推定（試作）

被災地の画像をまとめて入れると、写っている場所の市区町村を読み込み、能登半島地震（2024年）で学習した判定器で建物ごとの倒壊の確率を出して、「全壊は少なくとも何棟か」（最低値）を市区町村ごとに地図にする試作です。判定はすべてブラウザの中で行い、画像のファイルはどこにも送りません。

## 判定できる画像
- **航空写真のオルソ画像**（位置情報つきのGeoTIFF）：建物ごとに、外接長方形の中心に合わせた正方形（一辺は長い方の辺の1.6倍、20〜60 m）を切り出して判定します。座標系は経緯度、平面直角座標系（I〜XIX系）、UTM、ウェブメルカトルに対応しています。
- **地上の写真**（位置・撮影方向・35mm換算焦点距離の記録があるもの）：撮影位置から0.5°ごとに光線を出し、5〜30 mで正面に写る建物を切り出して判定します（1棟1枚）。
- 衛星・ヘリコプター・ドローンの画像は、判定器がないため数に入れません（種類と位置は見分けます）。

## 判定器
- 特徴量：Swin-B（ImageNet-22k、平均プーリング1024次元）。ブラウザ用に、全結合の重みを int8 にしています（約94 MB。確率の差は平均0.003）。
- 航空写真：能登2024の悉皆調査4,812棟（D5以上574棟）と国土地理院の正射画像（2024年1月、ズーム18）で学習。地区単位10分割の交差検証で AUC 0.81。
- 地上の写真：能登2024の悉皆調査232棟（D5以上78棟）と iPhone・ドラレコの写真で学習。AUC 0.86。
- 1棟に両方あるときは、地上の写真の判定を使います。
- 最低値：確率の合計 − 1.645√(Σp(1−p) + (0.11 × 確率の合計)²)。0.11は能登2024の検証で得た較正のずれです。
- ほかの地震や撮影条件では、精度が下がるおそれがあります。

## 使っているデータ
- 背景の地図：OpenStreetMap（© OpenStreetMap contributors）、国土地理院の地理院地図
- 建物の形：国土地理院 地理院地図Vector（ベクトルタイル optimal_bvmap-v1、拡大16の建物 BldA）
- 市区町村の境界：OpenStreetMap（Nominatim。政令市は区単位）
- 「試す」の画像：国土地理院「令和6年能登半島地震」正射画像（2024年1月2日、珠洲市宝立町鵜飼）
- 判定の計算：ONNX Runtime Web（jsDelivr から読み込み）、GeoTIFFの読み込み：geotiff.js
