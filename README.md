# 全壊棟数の最低値シミュレーター（試作）

衛星・航空機・ヘリコプター・地上・ドローンの画像をまとめて取り込み、写っている場所の市区町村を自動で読み込んで、建物ごとに倒壊の確率を出し、「全壊は少なくとも何棟か」（最低値）を市区町村ごとに示す仕組みの試作です。

- **建物の被害は模擬です。** 実在の建物の形に、乱数でつくった倒壊の確率を重ねています。実際の被害ではありません。
- 画像の種類（衛星・航空機・ヘリコプター・地上・ドローン）は、画像のメタデータ（ドローンの記録、地上解像度、撮影高度など）から自動で判定します。判定できないものは手で選びます。
- 画像の位置は、写真のGPS（EXIF・DJIのXMP）か、オルソ画像（GeoTIFF）の四隅から読みます。GeoTIFFは経緯度、平面直角座標系（I〜XIX系）、UTM、ウェブメルカトルに対応しています。
- 位置情報のない画像と模擬の画像は、地図の中心にある市区町村に入れます。
- 画像のファイルはどこにも送りません。市区町村を調べるために、撮影位置の緯度・経度（約100 mに丸めた値）だけをNominatimに送ります。

## 使っているデータ

- 背景の地図：OpenStreetMap（© OpenStreetMap contributors）、国土地理院の地理院地図（淡色地図・標準地図）
- 建物の形：国土地理院 地理院地図Vector（ベクトルタイル optimal_bvmap-v1、拡大16の建物 BldA）。市区町村ごとに、そのつど読み込みます（1市区町村15万棟・4,000タイルまで）
- 主な道路：同じタイルの道路中心線 RdCL（模擬の撮影範囲を置くためにだけ使います）
- 市区町村の境界：OpenStreetMap（Nominatimで読み込み。政令市は区単位）
- 地図の表示：Leaflet 1.9.4（ページに同梱）

## 置き方

`index.html` を1つ置くだけで動きます。サーバー側の処理はありません。
